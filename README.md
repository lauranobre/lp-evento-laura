# Festival Sabores da Alta Paulista

Landing page desenvolvida para o **Festival Sabores da Alta Paulista**, reunindo informações sobre o evento, programação, chefes convidados, formulário de inscrição, gráfico de vendas e suporte a notificações (PWA) com alternância entre tema claro e escuro.

## Tecnologias Utilizadas

- React + Vite
- Tailwind CSS v4
- Service Worker (PWA e Notificações)
- HTML5 Canvas
